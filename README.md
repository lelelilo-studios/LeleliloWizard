# Lelelilo Wizard

**Play: [lelelilo-studios.github.io/LeleliloWizard](https://lelelilo-studios.github.io/LeleliloWizard/)**

A floating pillow wizard casting elemental spells in a moonlit floating garden. Made for phones (hold it
landscape) in Chrome on Android or Safari 26+ on iPhone; it needs WebGPU.

This repository only holds the published build; it is updated automatically.
